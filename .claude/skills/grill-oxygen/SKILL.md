Call the Skill tool twice, for "grilling" and "oxygen-docs".

This is the OxygenQuiz counterpart to the generic `grill-with-docs`. Use this one in this
repo — it pairs the same interview with `oxygen-docs`, which writes into `docs/<area>/` and
`docs/proposals/` in the house format, instead of creating a root `CONTEXT.md` and a
`docs/adr/` folder this repo does not use.
